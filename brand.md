# Brand — AgentGuard

_Status: active_

AgentGuard is a calm, technical trust product for the agent-native web. The interface pairs a light US technology storefront with a dark operations console so people can see the boundary between commerce and control.

## Palette

- Store background: `#f4f5f2`
- Primary ink: `#1c2321`
- Muted ink: `#5c6b66`
- Border: `#dde3df`
- Card: `#ffffff`
- Brand: `#0d7a68`
- Brand dark: `#0a5e51`
- Panel background: `#101613`
- Panel card: `#1a2420`
- Panel ink: `#e2ece8`
- Panel muted: `#8fa39c`
- Panel border: `#27332e`
- Success: `#2fbf94`
- Warning: `#e0a03c`
- Danger: `#e05252`

Semantic colors are reserved for verdicts, alerts, approvals, and system state.

## Typography

Use the system UI stack for the storefront and a system monospace stack for AgentGuard data, tool names, amounts, hashes, and verdicts. Keep type compact and legible; never use display typography that competes with operational data.

## Voice

Use Simplified Technical English. Copy is short, active, calm, and precise. Explain why an action was blocked and what the person or agent can do next. Avoid fear-based security language.

## Shape and motion

Cards use consistent medium radii and flat borders. Controls have visible focus rings and touch targets of at least 40px. Motion is brief feedback for state changes only and must respect `prefers-reduced-motion`.
